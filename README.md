# Laravel & PHP Learning Project

A personal learning project created to explore **PHP syntax** and **Laravel fundamentals** through simple examples and small implementations. The project also uses **Inertia.js** to connect the Laravel backend with the Vue.js frontend and includes an authentication module.

## Tech Stack

- Laravel 10
- PHP
- Vue.js
- Inertia.js

## Features

- PHP syntax and Laravel practice examples
- Basic authentication module
- Laravel and Vue.js integration using Inertia.js
- Simple implementations for learning and experimentation

## Note

This is a personal practice project created mainly for learning and experimenting with PHP syntax, Laravel features, authentication, and frontend integration. The project may contain simple or incomplete implementations as part of the learning process.
